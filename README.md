# Student REST API

A Spring Boot RESTful API service built with Java 21, Spring Data JPA, Hibernate, and MySQL for managing student records.

---

## 🛠️ Tech Stack & Prerequisites

* **Java**: 21 (JDK 21)
* **Framework**: Spring Boot 3.x / 4.x
* **ORM & Persistence**: Spring Data JPA / Hibernate 7.x
* **Database**: MySQL 8.x / 9.x
* **Build Tool**: Apache Maven
* **Lombok**: Enabled for boilerplate code reduction
